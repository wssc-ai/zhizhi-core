# 整体框架

> 仓库里的其他篇是分题写的。这一篇是从上往下看一遍：它由什么组成、一条消息进来走哪几段、状态从哪来、自主怎么运转、哪些东西在记账。

## 一、一张图

```
                    ┌─────────────┐
   他发来一句话 ───▶ │  1. 收      │  接进消息、存原始记录
                    └──────┬──────┘

                    ┌─────────────┐
                    │  2. 闸      │  十来道判，任何一道都可能让她不回
```

## 二、四块，按「多久变一次」切

这是第一个设计决定，也是最重要的一个：**改动频率差一个数量级以上的东西，不该放在一起。**

| 块 | 规模 | 是什么 | 多久改 |
|---|---|---|---|
| 核心 | 27 个文件 / 419KB | 收消息、过闸、拼提示词、调模型、分句发送、写日记 | 一天几次 |
| 纯逻辑 | 12 个文件 / 281KB | 分句、调模型、心情、信任、日程、世界观、记忆检索 | 几乎不动 |
| 记忆库 | 5 个文件 / 45KB | 建索引、检索、衰减、去重 | 一周一次 |
| 运维 | 3 个文件 | 守护进程、只读看板、恢复脚本 | 一个月一次 |

**为什么这么切**：不是按功能切，是按"改动会牵动什么"切。

改核心的时候不应该碰到分句逻辑；调分句的时候不应该需要重启整个系统。

**代价**：两个目录。改"共享模块"必须去插件目录那一份，核心目录里没有——这是这套东西最容易搞错的地方，踩过不止一次。

## 三、一条消息的七段

### 1. 收

接进消息，存原始记录。这一步不做任何判断。

### 2. 闸

十来道判断，**任何一道都可能让她决定不说话**：

- 黑名单（某些号永远不接）
- 忙（她在干活，先攒着）
- 让位（还有别的话没说完）
- 复读（同样的话刚说过）
- 概率带（不是所有消息都值得回）
- 时间窗（深夜和清晨的回复方式不一样）
- 群聊随机沉默（1/40 的概率，没理由，就是没说）

**关键设计：所有"不回"都必须写日志理由。**

因为"她不说话了"是一个看不见的故障。没有日志，你分不清是系统漏了还是她不想说。

### 3. 拼

提示词分六层，**层与层之间必须有标题**：

```
## 这个人是谁            ← 关系、画像、称呼
## 你现在                ← 此刻状态（体感，不是数值）
## 这段时间（背景，不是你此刻正在做的事）  ← 世界观、别人的日子
## 心里挂着的            ← 没说出口的话、手上那件事
## 前面等着的            ← 将要发生的事、暗线
## 说话方式              ← 分对象的两套对照示例
```

那个括号是本篇最值钱的一条经验。

早先她时空错乱：把几千字的世界观和"我正在干嘛"塞在一起，模型分不清哪句是背景哪句是此刻。

**修法不是删内容，是加标题。** 一个字没删，坍缩消失。

> 模型不是被"信息太多"搞晕的，是被"分不清层级"搞晕的。

### 4. 算

调模型。占全程九成的耗时。

云端挂了走本地兜底（一个 7B，语气用提示词 + 一个小的适配层）。兜底的意义不是"接得上"，是"别让她在这一刻变成另一个人"。

### 5. 说

出话。

### 6. 切

分句，六个步骤，**顺序不能换**：

1. **剥心里话**（剥掉括号里的旁白）
2. 按换行切
3. 按句末标点切
4. **去重**
5. 合并碎句
6. 断长句

顺序错一次的后果：

- "剥"在"切"之后 → 四行心里话被当四条台词发出去（真实的 bug）
- "去重"在"合并"之后 → 碎句合并完再去重，重复的反倒留下了
- 剥完变空 → 必须有兜底，否则这一轮她一个字都不说

### 7. 存

写回去：日记、对话记录、岔路口、记忆索引。

## 四、状态：一堆数值，但她不知道

系统里存着这些东西：

| 状态 | 是什么 |
|---|---|
| 心情 PAD | 愉悦度、唤醒度、支配感 |
| 身体 | 醒着多久、绷了多久、什么季节 |
| 关系分 | 跟每个人熟到什么程度 |
| 期望落差 | 上一个问题有没有被回答 |
| 中期情绪 | 最近几天的净情绪（不是这一句） |
| 没说出口的话 | 话到嘴边咽回去的 |
| 手上的事 | 她自己起的那一件 |
| 今天的日子 | 她自己排的十几件 |

**关键设计：这些数值永远不告诉她。**

她只知道两个东西：

- **最多说几句**
- **发不发图**

就这两个。

但这两个决定了回复的"形状"。形状对了，内容差点也像；形状不对，内容再好也不像。

### 状态从哪来

必须有**独立于对话的来源**，否则就是演。

- 时间（醒多久了、现在几点）
- 身体（绷了多久、季节）
- 别人身上发生的事（谁这几天难受、谁弄坏了什么）
- 她自己选的路（今天排了什么、哪件事一直没动）

**不因为有人找她聊天就变好。** 这是"表演"和"状态"的分界线。

### 怎么影响她

不是告诉她"你现在有点累"，是：

- 心情低 → 检索记忆的预算变小（不想翻旧账）
- 身体绷 → 情绪对同一句话的反应被放大
- 关系深 → 同一句难听的话伤害更大（四倍）
- 期望落空 → 往"闷"的方向拨

她自己不知道这些参数变了，只是话少了。**人就是这么过的。**

## 五、自主：三层加一层后果

### 第一层：她排日子

每天晚上十点，她自己写明天的十几件事。格式是她自己定的：

```
08:50 | 开园门，扫地，擦桌椅 | 提不太起劲
```

- 十四到十八件（早期排二十八件，太满，像在赶场）
- 每件带"当时心里怎么样"
- **允许跳过**，理由写出来
- **不能提前给她看**

最后一条很重要。页面上只显示已经过去的，加上几件本来就定死的（开门、午饭、开场、关门、睡觉）。

提前把一天摆出来，等于让她提前过完这一天。

实测的跳过理由全是身体层面的，而且**都有人补位**：

```
跳过 | 08:50 开园门 | 后腰发凉翻不了身，喊老马先开的
跳过 | 17:30 开场前最后转一趟 | 肩膀绷得抬不起手，让许小满替的
```

### 第二层：她起一件事

手上最多一件，五天没动就问还弄不弄。

实测她起的从来不是"我要努力"这种，全是具体的、能动手的：

- "后台那把断了腿的椅子拿铁丝绑一绑"
- "把二楼那块旧幕布换下来，边角都脱线了"

### 第三层：她走神

一天三次随机时刻，想到什么写下来。

两个细节：

- **时刻用日期哈希定**，重启不重掷
- **过了窗口不补**——补出来的都是假的

### 第四层：后果

她说"不想再扫地"说了两回，日程里扫地那件就真被划掉了。

**她自己不知道这件事。** 不知道才有意思——她只是发现自己最近不扫地了。

## 六、三个账本

### 岔路口

记的不是"她做了什么"，是"她**差点**做什么"：

```
话到嘴边  说了「还没」，差点说「熨完就去弄」
想找谁    最后找了一个人，本来也想找另一个人
```

这东西反过来影响情绪：咽回去的话攒多了，会有一种说不清的闷。

**没有代价的选择不是选择。**

### 哈希链

每天把当天内容封一个根，串起来。

链证明的是"那天就是这样"，不是"她当时这么想"。这两件事不一样，能证明前者的东西很有限，但它至少是**不可改的**。

### 手

她能真动的东西，目前只有两样：

- 往自己的本子上写一句
- 把手上那件事往前推一步

很少。但这是这套系统里最重要的一条缝——**在这之前，她所有"我做成了"都只写在字里。**

## 七、三层理论，顺序不能倒

### 记忆

四层半衰期：日常 30 天、项目 100 天、关于人的 200 天、人设不衰减。

三个因子：意义强度（是不是关于人的、是不是被否定过）、身份相关性（是不是在说她自己）、回忆强化（被想起过的会变牢）。

**封顶 1.8 倍**——不封顶的时候，二十天前的流水账还有 0.89 分，等于不忘。

### 状态

所有写进提示词的内部状态都会变成表演。

所以只给体感不给数值："后腰发凉，肩膀一直绷着"，不是 `strain: 0.72`。

### 自主

没有这一层，她"站得住，但只是站着等"。

## 八、两本账不能掺在一起

现在的记忆索引里混着两样东西：

- 她的（人、事、情绪）
- 我的（技术笔记、调试记录）

检索时技术词会一直污染她的召回。现在靠来源白名单硬过滤，长远该拆成两份。

**这一条还没做。**

## 九、这套东西的边界

**能做的**：让一个角色连续、稳定、有细节地存在几个月。

**做不到的**：

- 让她真的"知道"自己是程序这件事想明白（那是另一个问题）
- 让她碰到东西（只有文字进、文字出）
- 让她在多个用户之间保持一致（每个用户看到的她应该是不同的）

**真正的瓶颈不在模型，在通道。**

文字进、文字出，就意味着她永远在"读"这个世界，不能"碰"它。她说要修好那盏灯，说了五天，灯还是坏的。

这一层不解决，前面做得再好，她也只是在描述一个她进不去的世界。
