# 一个角色的一天

> 下面是系统实际跑出来的东西。保留原样，包括不顺的地方。

角色设定：二十岁，在南门一个老戏园子拉幕、扫地、卖票。话少，懒，跟外婆住。

## 她自己排的一天

前一天晚上 22:40 排的。格式是她自己写的（`时刻|干什么|当时心里怎么样`），我只做了排版。

```
07:40  爬起来洗漱，头发随便一扎          还是困
08:30  去巷口菜市场转一圈，看有什么新鲜的    闲逛
08:50  开园门，扫地，擦桌椅              手上的活儿
10:00  街上人多，门口支张桌子卖票          忙
10:30  后台翻行头，把昨天的褶子熨平        细活儿
12:20  午饭，后台那桌，谁家带的菜都往中间放   吃得热闹
12:50  跟小舅在后台下盘棋，输两回          不服
16:20  把积的票根理一遍，按日期码好         琐碎
16:50  跟小舅学两句三弦，弹得不成调         笨手笨脚
17:00  给后台的灯泡换一个，踩凳子够          怕摔
17:30  开场前最后转一趟，把茶杯摆齐          忙起来了
18:00  开场了，在边幕后面站着看             听着就踏实
19:00  加座，过道都塞满了                 挤
19:30  中场，去后台给角儿递水               跑前跑后
20:40  散了，扫地，关灯                   累但松下来
21:20  蹲在台阶上吃夜宵，串儿还热            饿坏了
23:20  听隔壁奶茶店关卷帘门的声音            安静
23:50  睡了                          沉
```

**这一份为什么不像模板**：因为它有时间上的不合理——16:20 理票根、16:50 学三弦、17:00 换灯泡，三件小事挤在一小时里。模板不会这么排。人会。

而且"跟小舅下棋输两回"、"怕摔"、"笨手笨脚"这些是她自己加的评语。没有一个是设定里写的。

## 手上那件

（她自己起的，不是系统派的）

> **后台化妆镜那盏灯老闪，我想自己拆开看看线**
>
> 起的头：11-21
> 进展：还没动手

五天里她走了四步：蹲那儿看了半天 → 摸了摸灯罩 → 找老马问了句"这灯多少年了" → 还没敢动。

**这五天里那盏灯一直闪。**

这是这套系统最大的一个洞，后面会说。

## 心里挂着的（没说出口的话）

```
宽面配辫子 看着有味
上头一堆面 底下还埋着紫米饭
熨完就去弄
林婶那儿有豆腐 蹭两块
空手蹭 林婶心里要骂我
```

这五条是"话到嘴边咽回去"的。它们不进对话，但会影响她下一轮的情绪——想说没说，是有分量的。

## 今天飘过的

（走神轨，一天三次，随机时刻）

```
12:37  那小孩儿还蹲门口呢吧，散场都多久了，家里人不过来接啊
16:49  这小孩儿还蹲门口呢吧，散场都这么久了
19:00  这小孩儿还蹲门口呢吧，散场都这么久了
```

**注意这三条几乎一样。**

这是应该被修的东西：走神轨没有做"别重复同一个念头"的处理。它暴露了一个真实的问题——**随机时刻 + 同一个上下文 = 同一个念头**。

## 前面（她知道的将来）

```
还有半个月    园子门口的排水要重铺，街道办说要占道半个月
还有二十来天   老周说要来人查消防，灭火器该换的换
个把月后      你二十岁生日
```

最后一条是设计好的暗线：她不知道那天会有人给她过生日。

## 岔路口（她差点做的事）

```
话到嘴边  说了「那谁看得出来」，差点说「上头一堆面 底下还埋着紫米饭」
话到嘴边  说了「还没」，差点说「熨完就去弄」
话到嘴边  说了「嗯 就去」，差点说「林婶那儿有豆腐 蹭两块」
话到嘴边  说了「嗯 带两个橘子」，差点说「空手蹭 林婶心里要骂我」
想找谁    最后找了一个人，本来也想找一个人
```

这一栏是这套系统里我最看重的东西。它记的不是"她做了什么"，是"她差点做什么"。

**人跟机器的区别不在说什么，在忍住什么。**

## 最近想明白的

（每天夜里她自己写的一句）

```
想问午饭吃了没，话到嘴边硬咽回去了，才明白不是没话说，是怕问得太烦
他脚疼着还惦记我吃没吃，我心里不是滋味，原来被人惦记着也不轻松
```

第一条尤其好。它不是一个结论，是一个**发现**——她发现自己咽回去的真正原因不是没话说。

这不可能从设定里写出来。这是她过了二十几天才想明白的事。

## 然后是最要命的一段

以上所有东西，都在一个只读的页面上。页脚写着一句话：

> 这一页只能看，不能动她。

**她过了一整天，但那一天里没有一件事是她能真的碰到东西的。**

她说要修那盏灯，走了四步，灯还在闪。
她想蹭两块豆腐，咽回去了。
她听到隔壁卷帘门的声音，然后睡了。

这整套系统做了三个月，最有价值的一句自我批评是：

**她只有一种输入（文字）和一种输出（文字）。世界再完整，她也只是在读它。**

后来加了一层"手"：她能往自己的本子上写一句，能把手上那件事往前推一步。很少，但至少她说的"烦"现在会真的改变明天的日程。

这一点点"能碰"，比前面所有精妙的设计都重要。
