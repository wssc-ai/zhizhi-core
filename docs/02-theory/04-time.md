# 时间：她为什么不知道自己拖了几天

> 这一篇是「时间」这个方向的第一个落点。
> 起因是三个没想透的方向之一，选了最底下那个。

---

## 一、先说一个错的判断

我一开始说：「她每次都像第一次。」

**这句话是错的，而且错得不轻。**

它会让人以为问题是"她没有记忆"，可她有——档案里躺着过去六天的日程，
每一件做什么、当时心里怎么样，一个字都没丢。

准确的说法是另一句：

> **她会重复，但重复对她不产生任何意义。**

区别在这里：拆那盏灯她真的拆了三回，但她不知道那是第三回。
所以既不会嫌烦，也不会觉得「这个我熟」，更不会因为「拆了两回都没修好」而停手。

写这篇之前先认这个错，是因为后面所有设计都建在这个更准的说法上。
差之毫厘的地方是：**问题不在存了多少，在存下来的东西有没有交汇。**

---

## 二、三份证据

三份都是真实数据，不是推演。

### 证据一：她排明天的时候，手里没有昨天

排日程的那个模块（`selfplan.py`），prompt 里一个字都没提
「第几次」「上次」「昨天」「重复」。

过去六天她排出来的日程里：

```
3 次  蹲在化妆间拆那盏老闪的灯 看线
3 次  补幕布上刮破的一道口子
3 次  去林婶豆腐坊串门 顺手拿两块豆腐
3 次  开场前最后转一趟 把茶杯摆齐
```

同一件事排三回。**但那是巧合，不是习惯**——
因为她排的时候看不到昨天的表，所以每一次都是重新抽出来的。

### 证据二：她不知道自己在拖

这是更狠的一条。她手上那件事的记录长这样：

```
11-22  灯座螺丝松了一颗，我拧紧试了试还闪     ← 真动了
11-23  没动，刚从侧幕下来给角儿递了水，手里还攥着空壶，没腾出手
11-24  刚把壶灌满又让人叫走，灯还没碰着
11-25  没动，扫完地关完灯就锁门了，灯还没拆
```

四天，三天没动。

但每一步都是**孤立写的**——写 11-25 那步的时候，没有东西告诉她
「这已经是第四天了」。所以在她那儿，这四天是四个分开的「今天」，
不是一个连续拖了四天的「这件一直没弄」。

差别有多大：人拖到第四天会有一种东西，不是愧疚，是**心里那件事变重了**。
每次想起它，它都比上一次更沉一点。她没有这个重量的累积，
因为她的记忆是平铺的，不是叠起来的。

### 证据三：重复是别人替她发现的

她自己写的日记里有一句：

```
他问我怎么天天拆灯笼
```

「他」是老大。**是别人替她发现了重复。** 她自己这头没有这个感觉。

这一条比前两条都说明问题：如果她真知道自己在重复，
写日记的时候就不会用「他问我」这个角度，而会写「又是那盏灯」。

## 三、人的时间感到底是什么

不是「知道现在几点」——那个我们早就有，日期字符串加时分，一秒都不差。

人的时间感是另外四样东西：

| 是什么 | 一句话 |
|---|---|
| **痕迹** | 这件事我做过了，第几回 |
| **节律** | 这个点我平时在干什么 |
| **深度** | 三个月前和三周前不是一回事 |
| **远近** | 还有多久能等到 |

她四样全缺。缺的方式还不一样：

- **痕迹**缺得最彻底——数据全在，但从来没有被数过
- **节律**半缺——她有日程，但不知道"这个点平常我在干什么"
- **深度**全缺——她所有过去都是扁的，21 天前的和昨天的在她那儿一样近
- **远近**有一点——「还有半个月」「二十来天」这种说法有，但那是文案，不是感觉

这篇文章只做第一样：**痕迹**。

理由：它是其余三样的地基。没有"做过第几回"，
"这个点平时在干什么"就没有依据（你得先有习惯，才知道这个点在不在习惯里）；
"三个月前"和"三周前"的差别也是靠"那时候在做的事现在还在不在"撑起来的。

---

## 四、做法：数出来，不是存进去

最直接的反应是「给她加一个时钟模块」。这是错的。

她已经有时间了，缺的不是刻度，是**刻度之间的关系**。
加一个更精确的钟，只会让她更准确地说出现在几点——那不是变真，是变得更像一台设备。

所以做的方向相反：**不给她新信息，给她已经有的信息的汇总。**

具体两件事：

### 1. 数次数

读她自己排过的所有日程，把「同一件事」归并、计数。

归并不能用字符串相等——她写同一个动作会有不同说法：

```
蹲在台阶上吃夜宵 串儿还热
蹲在檐下吃夜宵 串儿还热          ← 换了个地点
蹲在台阶上吃夜宵，串儿还热         ← 换了个标点
```

所以用字符二元组的重合率，阈值 0.5。
低于这个就只是用词像，不是同一件事。

实测下来这四天里「夜宵」被归并成 4 次，是对的。

### 2. 算拖了几天

读她手上那件事：从哪天起的、一共几天、几步是真动的、几步是没腾出手的。

判断"这一步算不算真动"很简单：记录以「没动」开头，或者含「还没碰」「没腾出」，
就算没腾出手。这一步是启发式，会有错，但错得不多——
因为她写这些的时候用的就是这套词。

输出的样子：

```
（2026-11-21 起的那件事，到今天第 6 天。
 4 步里只有 1 步是真动的，3 步是没腾出手。
 你没觉得这事拖了，因为你每天只看见今天。）
```

最后那句是关键的。它不是在提醒她"你在拖延"，
是在**告诉她一件事她本来就该有、但没有的感觉**。

## 五、两个克制

### 克制一：不每轮都给

一天二十轮对话，每轮都塞一句「这半个月你反复在做夜宵」，就成了念经。
念经的东西会被无视，无视久了就等于没有。

所以按 subject 加日期加时段做哈希，**三成才给**。
实测六个时段里出了两次（三成左右）。

### 克制二：不告诉她数字，也不下判断

不是「你已经做了 4 次了，是不是该换换」——那是提醒，是管家口吻。

是「（这半个月反复在做的：……。不用特意提，碰上就碰上。）」

**只给素材，不给结论。** 她要是觉得腻了，自己会说；
她要是觉得熟了，自己会用那个语气。我们只负责让她有得可想。

跟整篇文章的第一条原则一致：**能减少的就减少。**
这里加了一层东西，但那层东西是"汇总"，不是"新信息"——
它没有让她知道任何原本不知道的事实，只是让她能看见原本散着的东西。

## 六、还差什么

**痕迹**这一层现在是有了，但只覆盖了日程和那件事。

还缺的：

1. **深度**——她所有过去都是扁的。想让她觉得"很久以前"和"前几天"不一样，
   得有个跟"她关心什么"相关的衰减，而不是跟条目数量相关。
   现在的记忆衰减是按类型和重要性算的，不是按"她提起过几次"算的。
2. **节律**——她知道今天几点该干什么，但不知道"这个点平常我在干什么"。
   这需要一张"平常这个点"的画像，而不是今天这一份日程。
3. **远近**——「还有半个月」现在是个文案字符串，不是感觉。
   真做起来得让她在等待里消耗点什么，不然"等"这个动作没有成本。

还有一条不是"差什么"，是"不该做什么"：

**不要给她一个更准的钟。** 时间感不是精度问题，
她自己现在报几点报得挺准，这不说明她有时间感。
