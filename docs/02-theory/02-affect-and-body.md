# 情绪与身体

> 情绪不是她说话时的腔调，是她今天就少说两句。

## 先说错的做法

一开始我们是怎么做情绪的：在系统提示词里写"你现在心情有点低落，说话可以软一点"。

结果是灾难。模型会**演**这个低落——每一句都软，包括该硬的时候。而且它会解释自己："我最近有点没精神"——真人不会这么说，真人只会话变少。

**凡是被写进提示词的内部状态，都会变成表演。**

所以后来定了一条规矩：**内部状态不写进提示词，只改变参数。**

她心情差的时候，提示词里一个字都不提，但：

- 这轮最多发几条，从 2 变成 1
- 发表情的概率，从 0.5 变成 0.1
- 检索记忆的预算减半
- 句子长度上限从 45 字变成 28 字

她不知道参数变了。她只是话少了。

这就是人过的日子。

## 三层，顺序不能倒

要做出这个效果，得先承认一件事：情绪不是平白来的。它下面有东西。

**第一层：底子**

一个要花代价才能维持的量。醒了多久、累不累、什么季节。它有阈值、会消耗、会恢复。这一层不产生任何感觉，只产生"偏离"。

这一层的特点：**慢，而且改不了。** 你不能命令自己"从现在起我不困"。所以它必须由一个独立的时间轴来推，不能由对话内容来推。

**第二层：偏离转成情绪**

偏离的幅度 + 强度 + 还有没有解法，合成两个轴：好受/难受（P）、起劲/蔫（A）。

这一层才第一次出现"我"。但这时的"我"很粗，只有两个维度，没有内容——就是"不对劲""舒服"。

**第三层：转成意义**

把"我现在难受"接到"因为他刚才说了那句话"上。

这一层才是我们平常说的"心里在想什么"：有对象、有理由、有前后。但它是**在解释**下面两层，不是在产生它们。

**顺序不能颠倒。** 常见错误是先写第三层（让她解释自己的情绪），然后假装第一二层存在。这出来的东西一定是编的。

## 底子怎么实现

三个量，每个都是 0~1：

| 量 | 意思 | 怎么变 |
|---|---|---|
| `wake` | 醒了多久 | 按真实时间走，过了夜就重置 |
| `strain` | 累积的疲惫 | 干活涨、睡觉掉，慢衰减 |
| `season` | 时段和季节 | 深夜、冬天各带一点偏移 |

它们各自产出一点点偏离，加起来推情绪：

```
醒超过 16 小时   → P -0.16  A -0.12  D -0.10
strain 超过 0.7  → P -0.18  A -0.14  D -0.12
深夜             → A -0.06
冬天             → D -0.03
```

注意幅度都不大。这是故意的：身体不该决定她的情绪，只该**给个底子**。三五个小偏移叠在一起，加起来还不如一句难听话的分量。

**这里踩过一个坑，值得单说。**

最早判断"睡过没睡过"是用时间差：如果距上次心跳超过 6 小时，就当睡过了。

但核心是 24 小时不断跑的，心跳只隔几秒。**这个条件一辈子不成立。** 结果 `wake` 只增不减，涨到 31.6 小时——她"醒了 31 小时"，永远疲惫。

修法是改成按日期判断：日期变了就算过夜，时间差只用来兜机器真停过的情况。

一个只看时间的 bug 能跑一星期不被发现，因为它的表现不是崩，是"她一直有点累"——很像真的。

## 怎么把状态给她看

底子算出来是数字，但**不能把数字给她**。

如果提示词里写"你现在 wake=0.83 strain=0.71"，她会直接说出来——"我有点累"。那是报告，不是感受。

所以只输出症状：

```
眼皮沉，脑子有点木
后腰发凉，肩膀一直绷着
```

这些是"从里面感觉到的样子"，不是"测量值"。她自己读到这个，会自然地少说两句、句子变短。

**判据**：同一句话说给不同的身体状态，她的反应应该差三成以上。实测：36% 和 184%（后者是极端情况，同一句在 strain 0.9 和 0.1 下的情绪读数差）。

## 状态放大感受，不是替代感受

还有一个细节：情绪不是简单加法。

同一句"你是不是又不理我了"：

| 状态 | 感受强度 |
|---|---|
| 平静 | 0.54 |
| 蔫到底 | 0.33 |
| 来劲 | 0.66 |
| 心情本来就差 | 0.73 |

**蔫的时候钝，来劲的时候敏，本来就不好的时候雪上加霜。**

系数大致是：A 小于 -0.35 时乘 0.62，A 大于 0.45 时乘 1.22，P 小于 -0.35 时乘 1.35，最后夹在 0.35~1.9 之间。

这一条让她的情绪有惯性。同样一句话，在好日子里是玩笑，在坏日子里是刺。

## 期望与失望

最后一层：她得会**等**。

她问了句"吃了没"，就是在等回答。如果对方答了别的，或者干脆没答，那就有落差。

实现上很土：她说出去的话以问句结尾时记一笔（记下问句的权重、时间）。对方回话时结算——按字符重叠判断"答上了没有"。

**这里有个必须用单字的坑。**

一开始用二元组判断重合："你最近是不是挺累的" vs "是有点累，作业太多了"——二元组一个都不重合，判成"没答"，然后扣分。

但人一眼就能看出答上了。

改成单字重叠，宁可多判"答上了"，也不要误判"没答"。**误判的代价不对称**：少扣一次分，没事；多扣一次分，她的情绪会莫名其妙地变差，而且原因追溯不到。

而且只在私聊里记。群里没人接话很正常，那不叫敷衍。

## 一句话总结

**情绪要有代价，否则就是台词。**

她心情差，不是说话变软了，是今天少说了两句、少发了一张图、少翻了两条记忆。这才是情绪。
