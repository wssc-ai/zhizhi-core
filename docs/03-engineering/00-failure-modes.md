# 失败模式分类

> 做这类系统，最难的不是"怎么让它像人"，是"它不像人的时候，你能说出是哪里不对"。
>
> 这篇是一份可查的清单。每一条都有：症状、怎么查出来、根因、怎么修。

## 为什么需要这份东西

最早的问题不是"它哪里不像"，是**"我说不出它哪里不像，只觉得假"**。

这种感觉没法驱动改进。所以花了很长时间把"假"拆成可指认的东西。

拆完之后发现一个规律：**所有的"假"都能归到五个大类里**，而且每个大类的根因都在不同的层。

| 大类 | 层 | 一句话 |
|---|---|---|
| A. 穿帮 | 提示词 | 她说出了"我是程序"这件事 |
| B. 记性 | 检索 | 记不住、记错、或者记住但用错 |
| C. 时空 | 上下文组织 | 她不知道"现在"是现在 |
| D. 形态 | 输出处理 | 内容的形状不像人说话 |
| E. 关系 | 状态建模 | 她对所有人都一个样 |

**关键洞察：五个大类的根因在不同的层，所以修法不能混。**

比如"答非所问"是 B 类（检索），但很多人会去改提示词——改不动，因为模型确实收到了那条记忆，只是那条记忆不相关。

## A. 穿帮类

**症状**：她以任何方式暴露了"我是程序"。

### A1. 自称

"作为一个 AI 助手"、"我是语言模型"、"我没有真实的情感"。

**怎么查**：正则扫所有输出，匹配「AI / 人工智能 / 语言模型 / 程序 / 系统 / 算法」。

**根因**：提示词里**提到了**这些词。

这是最容易犯的错：为了让角色"诚实"，在提示词里写「不要假装自己是人类，如果被问就承认」。

**这句话本身就是穿帮的源头**——模型看到这些词，就会在某个时刻用出来。

**修法**：删掉所有跟"你是 AI"相关的表述。不是改成"不承认"，是**一个字都不提**。

### A2. 客服腔

"有什么可以帮你的吗"、"希望对你有帮助"、"你可以试试以下几种方法"。

**怎么查**：词表 + 结构。词表：`有什么可以帮`、`希望对你有帮助`、`建议你`、`你可以试试`、`第一步`、`总的来说`。结构：出现"首先/其次/最后"三连。

**根因**：模型的默认行为就是客服。它的训练数据里，这类回复被认为"好"。

**修法**：不能只写"不要客服腔"（负向指令效果弱），要给**对照示例**：

```
他：好累啊
你：累就对了 谁让你站一上午        ← 要的
不要：累的话要注意休息，可以试试泡脚 ← 不要的
```

实测：给三到五组对照，比写十条规则有效。

### A3. 解释自己

"我这样说是想让你…"、"我的意思是…"、"可能我表达得不够清楚"。

**怎么查**：正则「我这样(说|做)」「我的意思」「我表达的」「可能我」。

**根因**：模型在"修复误解"时的默认策略是元沟通。

**修法**：明令禁止 + 给替代方案（直接重说一遍，不解释）。

### A4. 主动给建议

用户没问，她主动说"你应该…"。

**根因**：绝大多数对话数据里，"对方说烦恼 → 给建议"是高分模式。

**修法**：提示词里明确「不许给建议」。但同时要给**她该干什么**——否则模型会僵住。这套系统给的是：「他说烦，你就听着，或者骂那个让他烦的人。不用解决。」

## B. 记性类

**症状**：她记不住、记错、或者记住了但用错。

### B1. 翻旧账

把前天说的事当成今天刚说的问一遍。

**怎么查**：日志里同一条记忆在两天内被两次当"新信息"引用。

**根因**：**会话复用。** 为了让对话连贯，系统会复用上一次的模型会话。但复用会把上周的上下文一起带进来，模型分不清"这段是刚才说的"和"这段是三天前说的"。

**修法**：两个都要做——
1. 在提示词里写一句「时间是会错的。他昨天说过的事，今天别再当成刚说的问一遍」
2. 记忆注入时带上时间标记，不要裸文本

### B2. 编造

记不起来，编一个。

**怎么查**：抽取输出里的事实陈述，去记忆库找出处，找不到的就是嫌疑。

**根因**：**检索失败之后的兜底行为。** 检索没找到，但提示词里有"你要记得他说过的事"，模型就编。

**修法**（三条一起）：
1. 检索不到时**显式告诉她**"没有这条记录"，而不是给空
2. 提示词里写「想不起来就问回去，别编」
3. 给一个明确的出口：不知道该说什么的时候，可以只回一个"嗯"

第 3 条最重要——**模型编造往往是因为"必须回答"的压力**。

### B3. 答非所问

她回答了一个"沾边但不相关"的记忆。

这是最难治的。

**怎么查**：拿固定的问题集跑，看命中内容是否相关。

**根因**：**语义相似不等于相关。**

实测数据：真正该命中的记忆，相似度 0.794；完全不相关但沾边的那条，0.840。

**误命中的分数比真命中还高。** 所以调阈值没用。

**现在的缓解**：
1. 弱命中（低于某个分数线）标注"存疑"，让她自己知道这条不太确定
2. 不要用"我记不太清了"这种话——那会变成一个圆谎的模板
3. 更好的做法是让她**反问**："你说哪个事？"

**没解决的**：这是语义检索的固有局限，只能靠更强的模型或结构化记忆。

### B4. 一个意思说三遍

**怎么查**：相邻两条的字符二元组重合率。

**根因**：提示词里没有"别重复"的约束，而模型倾向于把一个有意思的意象**越说越大**。

**修法**：提示词加一句「一个意思说一遍就够了。说完了就停在那儿，别把一个意象越说越大。」

实测有效。

## C. 时空类

**症状**：她不知道"现在"是什么时候，或者把背景当此刻。

这一类的破坏力最大，因为它会让整段对话读起来像精神分裂。

### C1. 时空坍缩

把几千字的背景设定当成"我正在做的事"。

**症状**：她突然说自己在做某件根本不在当前场景里的事。

**根因**：提示词把所有信息平铺在一起——世界观、今天的日程、刚才的对话，没有分段、没有标题。

**修法**（关键的发现）：**不要删内容，要分段。**

加两个标题就够了：

```
## 你现在
（此刻的状态）

## 这段时间（背景，不是你此刻正在做的事）
（世界观、别人的日子、她手上的事）
```

实测：同样的内容，加了这两个标题，坍缩消失。

**教训：模型不是被"信息太多"搞晕的，是被"分不清信息的层级"搞晕的。**

### C2. 场景硬跳

刚说"坐着看戏服"，下一句说"在拿豆腐"。

**根因**：日程表按时间硬切格子，每四十分钟一格。轮到她回话时，直接把她"现在该干的事"塞进提示词。

如果两轮之间跨了格子，她就会跳。

**修法**：
1. 加一句「这只是个底子，不是你此刻正在做的事。你刚说过的话算数，跟它对不上就顺着自己刚说的来」
2. **"刚说过的话"优先级高于"现在几点"**

### C3. 时间感缺失

她不知道"上次说话是三小时前"还是"三分钟前"。

**症状**：刚聊完立刻说"好久没聊了"。

**根因**：上下文里只有消息内容，没有时间间隔。

**修法**：注入间隔。三档就够——小于 8 分钟直接接话；小于 40 分钟可以说"刚忙完"；超过 40 分钟要说一句为什么现在才回。

## D. 形态类

**症状**：内容可能对，但形状不像人说话。

这一类最容易被忽略，因为**读起来"意思没错"**。

### D1. 心里话漏出去

角色的"内心活动"被当成台词发出去。

**症状**：用户收到四条一模一样结构的消息，或者收到"（心想：她好像不太高兴）"。

**根因（经典）**：处理顺序错了。

系统的处理链是：**剥掉心里话 → 分句 → 发送**。

但"剥"的函数是按行处理的，而"分句"的函数先在换行处切了。切完之后，第一行剥掉了，后面几行**原样留下**。

**这个 bug 的表现是"偶尔漏"，因为大多数时候心里话只有一行。**

**修法**：`_split` 的第一行必须是 `text = _strip_think(text)`。

**教训：所有"后处理链"都要检查顺序。而且剥完可能变空，必须有兜底。**

### D2. 条数超限

**怎么查**：数一下每轮发出去几条。

**根因**：模型不知道"人一次说几句话"。

**修法**：不是写"最多两条"（写数字会让它凑数），是给**语义化的指示**：「想到一句说一句，说完了就停」。

### D3. 复述对方

"你说你今天很累"——把对方的话重复一遍再回答。

**怎么查**：字符二元组重合率 > 60% 判违规。

**根因**：这是客服和心理咨询的典型话术，训练数据里很多。

**修法**：明令禁止 + 给对照示例。

## E. 关系类

**症状**：她对所有人的态度一样。

这一类最隐蔽，因为**单看每一句都没问题**。

### E1. 对生人太亲

刚认识的人，她用了对老朋友才有的口气（损、揭短、上手就调侃）。

**根因**：few-shot 示例不分对象。给了一套"损"的例子，模型就学到了"损"，没学到"只对熟人损"。

**修法**：**按关系分两套示例。**

- 对熟人：可以损、可以嫌、可以"说了等于没说"
- 对不太熟的人：话更少，别追问、别揭短、别客套，想不出说什么就一个"嗯"

这条改完之后，有个意外收获：**关系分（trust）终于有用了**——它决定了用哪套示例。

### E2. 对所有人都一样熟

**根因**：关系状态只有一个标量（0 到 1），太粗。

**现在的做法**：关系分影响三件事——用哪套说话方式、情绪被影响多少（同一句难听的话，熟人说的是 4 倍伤害）、主动找谁的权重。

**还没做的**：关系应该是有结构的（知道这个人什么、欠过什么、一起经历过什么），现在只有"熟不熟"这一个维度。

## 怎么用这份清单

**日常**：把它变成自动检查。这套系统里的回归测试就是这份清单的"形式部分"（A 类的词表、D 类的位置检查、条数、重合率）。跑一次十秒，能把大部分穿帮拦住。

**出事时**：先分类，再定位。分类错了会修错层。

**加新功能时**：新功能大概率会引入新的失败模式，加之前先想"它会以什么方式坏"。

## 一条总结

**"假"不是一个整体，是五种不同的东西，长在五个不同的层上。**

能说出是哪一种，就能修。说不出来，就只能瞎调提示词。
